# Solidtime

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Modern open-source time tracking for freelancers and teams, running on your Home Assistant
server.

[Solidtime](https://www.solidtime.io/) tracks time against clients, projects and tasks, with
billable rates, reports and a desktop app. This app bundles Solidtime with its own PostgreSQL
database, so it works on its own with no other apps required.

- Creates the first account for you.
- Generates every key Solidtime needs; nothing to set up by hand.
- Keeps all data in Home Assistant backups.
- Works with the Solidtime desktop app and API tokens.

See the **Documentation** tab for installation and configuration.
